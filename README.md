DevTrack is a responsive web application developed to simplify bug tracking and issue management for software development teams. It provides a centralized interface where users can create projects, document bugs, assign responsibilities, monitor tasks, and review development progress. The current version is a frontend prototype developed using React.js, JavaScript, and CSS. Browser LocalStorage temporarily maintains application data without requiring a connected backend or database. The project demonstrates practical frontend development concepts, including component-based design, routing, user interaction, responsive layouts, and state management.
